# 桌面能力

桌面能力不是写死在壳里的脚本，而是以 **host 插件**形态注册进 Harness 的插件树——它们可被列出、可被增删，也会在会话轨迹中留痕。

## 托盘驻留

关闭窗口不会退出应用：宿主进程继续在托盘驻留，任务照常运行。托盘菜单可以查看状态并退出应用。

## 全局热键唤出

默认热键为 `Ctrl + Shift + Space`，在任意应用中按下即可呼出快速输入，输入问题回车即发出。热键可在 **设置 → 桌面** 中修改。

## 系统通知

以下情况会触发系统通知：

- 任务完成；
- Agent 需要你审批某个操作；
- 运行出错。

点击通知会直接聚焦到对应的会话窗口。

## 开机自启

可在 **设置 → 桌面** 中开启，让应用随系统启动并驻留托盘。

## `dsh://` 协议唤起

应用注册了 `dsh://` 协议，可以从浏览器、终端或其他应用唤起桌面端：

| 形式 | 作用 |
| :--- | :--- |
| `dsh://open?session=<会话 ID>` | 定位并打开指定会话 |
| `dsh://ask?q=<问题>` | 打开快速输入并预填问题 |
| `dsh://settings` | 打开设置 |

::: warning 来源校验
为防止任意网页唤起本机应用，协议链接会经过来源校验：来自受信任来源的请求正常执行；来自未知来源的请求会被**降级**（例如仅允许聚焦已有会话，不允许新建）或直接**拒绝**，并记录审计日志。相关开关位于 **设置 → 桌面**。
:::

## 零端口

桌面端默认**不监听任何 HTTP 端口**，界面通过自定义协议加载、数据经 IPC 载波传输。你可以用下面的命令自行验证：

```powershell
netstat -ano | findstr "LISTENING" | findstr "308"
```

正常情况下不会输出与应用相关的监听记录。

## 可审查

托盘点击、通知、热键、协议唤起等桌面动作都会写入结构化日志与审计记录；涉及敏感操作（如写剪贴板、删除文件、跳转外链）时会先经过审批服务。
