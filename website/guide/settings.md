# 设置

设置入口在侧栏底部。通用、模型、插件等分区沿用官方界面，桌面侧新增了「桌面」与「外观」两个分区，以及独立的「关于」页。

## 桌面

| 设置项 | 说明 |
| :--- | :--- |
| 托盘 | 关闭窗口后是否驻留系统托盘 |
| 通知 | 任务完成 / 需要审批 / 出错时是否发送系统通知 |
| 全局快捷键 | 呼出快速输入的热键，默认 `Ctrl + Shift + Space` |
| 开机自启 | 随系统启动并驻留托盘 |

协议唤起相关的来源授权开关也在这里。

## 外观

外观分区从上到下是四项一级设置项：

1. **应用图标** —— 窗口与任务栏图标；
2. **托盘图标** —— 系统托盘图标；
3. **品牌 logo** —— 界面内展示的产品标识；
4. **图标包** —— 卡片网格形式管理，可切换内置包，也可**新建包**。

前三项是**全局单份**设置：存放在数据目录的 `icons/` 下，不随图标包切换而改变。

图标包下面是**界面图标需求清单**（默认折叠）：按消费方插件分组，逐行列出每个图标槽位的当前状态，可直接上传或替换单个图标。没有提供图标的槽位会自动回退到内置图标。

## 关于

「关于」页包含更新设置：

- **更新渠道**：稳定版 / 预发布 / 关闭；
- **自动检查更新**：开关（渠道设为关闭时联动置灰）。

详见[更新与渠道](./update)。

## 数据与隐私

- API 密钥、会话记录等用户数据都存放在你选择的数据目录中，不会随安装包迁移；
- 使用统计默认本地化处理，外发仅限官方模型 API 与你主动启用的网络能力。
