# 安装与首次启动

## 下载

前往 [GitHub Releases](https://github.com/lansi-ai/dsh-forge/releases) 选择最新版本。产物说明与校验方式见[下载页](/download)。

## 安装

Windows 安装包是**一键式**的：双击 `DSH-Forge-<版本>-setup.exe` 即开始安装，**不需要管理员权限**，也不会出现安装向导（安装位置固定在当前用户目录）。

不想安装的话，可直接使用同版本的**便携包** `DSH-Forge-<版本>-portable.exe`。

## 首次启动：选择数据目录

第一次启动时，应用会请你指定一个**数据目录**（即 `DSH_HOME`）。这个目录决定：

| 内容 | 存放位置 |
| :--- | :--- |
| 会话记录、存储、主题、图标、窗口状态 | 你选择的**数据目录**（`DSH_HOME`） |
| 设备相关状态（指针、Chromium 缓存、审计日志） | 系统用户数据目录（随设备走，不随数据目录迁移） |

如果你此前已经用 `dsh web` 工作过，**选择同一个目录**即可直接读到既有会话历史，两边数据完全兼容。

首次启动时应用还会提示是否**迁移旧数据**（若检测到历史遗留目录）。迁移会把旧目录下的用户数据搬到新数据目录，数据量大时需要一点时间。

## 用参数指定数据目录

需要固定目录或脚本化启动时，可用命令行参数：

```powershell
"DSH Forge.exe" --data-dir "D:\DSH-Home"
```

指定后，首次启动不再询问目录。

## 卸载与数据

卸载时应用会**询问是否同时删除用户数据**：

- 选择「保留」：数据目录原样留在磁盘，重装后可直接继续使用；
- 选择「删除」：应用会在完成路径安全校验后删除其数据目录。

## 系统要求

- Windows 10 / 11（x64）
- macOS 产物随 CI 构建（dmg / zip，arm64 与 x64），尚未实机验证
