# 常见问题

## 我的数据存在哪里？

存放在首次启动时选择的**数据目录**（`DSH_HOME`）。会话记录、存储、主题、图标、窗口状态都在这里。

设备相关状态（指针、Chromium 缓存、审计日志）留在系统用户数据目录，随设备走，不随数据目录迁移。详见[安装与首次启动](./install)。

## 能和 `dsh web` 同时用吗？

可以。两者共享同一个 `DSH_HOME`，会话历史、凭据与主题完全互通。桌面端默认零端口，不会与 `dsh web` 抢占监听端口。

## 桌面端会占用端口吗？

不会。桌面端默认不监听任何 HTTP 端口，界面通过自定义协议加载、数据经 IPC 载波传输。验证方法见[桌面能力](./desktop)。

## 卸载后数据会丢吗？

不会自动删除。卸载时会询问是否同时删除用户数据：选择「保留」则数据目录原样留在磁盘，重装后可直接继续使用。

## 图标是自有的还是官方的？

窗口、任务栏、托盘与安装包图标都是 **DSH Forge 的自有品牌标识**；应用内运行的内核与官方 DeepSeek Harness 一致，但外观标识属于本项目。

系统级图标（应用图标 / 托盘图标）与界面图标都可以在 **设置 → 外观** 中替换成你自己的图标包。

## 为什么版本号带 `alpha`？

项目处于预发布阶段，功能与界面仍在快速迭代。想接收后续预发布更新，请在 **设置 → 关于** 中把渠道切到「预发布」。

## 安装包没有代码签名，会有提示吗？

Windows 可能提示「未知发布者」；macOS 首次打开可能需要在「系统设置 → 隐私与安全性」中放行。当前未使用商业代码签名证书。

## 怎么反馈问题？

在 [GitHub Issues](https://github.com/lansi-ai/dsh-forge/issues) 提交，附上版本号与复现步骤。若涉及启动异常，可用 `DSH_VERBOSE=1` 环境变量启动以获取详细日志。

## 这是官方项目吗？

不是。DSH Forge 是独立社区项目，与 DeepSeek 官方无附属关系；相关商标归其各自所有者。
