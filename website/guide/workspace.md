# 工作区与会话

## 工作区是什么

一个**工作区**就是一个项目目录。会话归属于工作区，Agent 的文件读写与命令执行都发生在该目录内。

- 可以添加多个工作区，随时切换；
- 每个工作区的会话历史相互独立，便于按项目归拢；
- 选中某个工作区后，新建的会话默认落在该工作区下。

## 添加与切换工作区

1. 点击侧栏的**选择工作区**；
2. 从列表中选择一个已有工作区，或点击底部**添加**选择新的目录；
3. 选中后，侧栏会展示该工作区的会话树。

如果当前还没有任何工作区，点击入口会直接打开系统目录选择器。

## 会话列表

侧栏的会话列表支持两种视图与两种排序：

| 选项 | 可选值 | 说明 |
| :--- | :--- | :--- |
| 分组 | 按工作区 / 单列表 | 按工作区分组时以工作区为容器展示会话；单列表则平铺所有会话 |
| 排序 | 手动 / 最近更新 | 手动排序可拖拽调整并持久保存；最近更新按活跃时间排序 |

会话行会带状态标记：**待审批**（琥珀）优先级最高，其次是**运行中**（蓝），最后是**已完成**（绿）。

## 内容搜索

在会话列表顶部可以按关键词搜索。搜索同时匹配：

- 会话标题与工作区名（本地匹配）；
- 会话内容（经宿主检索）。

结果会合并去重后按相关度展示，命中较多时先展示前一批。

## 归档会话

不再需要的会话可以归档，归档后不会出现在常规列表中，但数据仍保留在数据目录里。
