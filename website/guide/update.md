# 更新与渠道

DSH Forge 通过 GitHub Releases 分发更新，应用内置自动检查与下载安装流程。

## 三个更新渠道

在 **设置 → 关于** 中可以切换渠道：

| 渠道 | 对应更新描述符 | 适用场景 |
| :--- | :--- | :--- |
| 稳定版 | `latest.yml` | 日常使用，只接收正式版本 |
| 预发布 | `latest-rc.yml` | 想第一时间体验新特性，接受可能的回归 |
| 关闭 | —— | 完全停用自动更新检查 |

::: tip 当前版本属于预发布渠道
`v0.1.1-alpha.*` 属于预发布版本。想收到后续 alpha 更新，请在「关于」页把渠道切到**预发布**。
:::

## 自动检查

「关于」页的**自动检查更新**开关控制是否在启动后静默检查：

- 关闭渠道时该开关联动置灰；
- 重新开启后，检查会立即补做一次，无需重启。

## 更新流程

1. 应用检查到新版本后下载安装包；
2. 校验完成后提示重启；
3. 重启后即为新版本。

用户数据存放在独立的数据目录中，**升级不会影响会话与设置**。

## 手动下载升级

也可以直接前往 [Releases](https://github.com/lansi-ai/dsh-forge/releases) 下载新版本安装包覆盖安装，效果相同。

## 回退

预发布渠道的版本可能存在回归问题。需要回退时，下载对应历史版本的安装包覆盖安装即可。注意：回退不会自动迁移或清理数据目录，而新版本可能写入旧版本不认识的数据，**重要会话建议先备份数据目录**。
