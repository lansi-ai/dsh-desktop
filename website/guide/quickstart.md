# 快速上手

本页假设你已经完成安装并启动了应用。如果还没有，请先看[安装与首次启动](./install)。

## 1. 配置模型

打开 **设置 → 模型**，填入你的 DeepSeek API 密钥并保存。

保存后模型路由**立即生效，无需重启**。密钥保存在你的数据目录中，不会写进任何配置文件。

## 2. 选择工作区

点击侧栏的**选择工作区**，把你要交给 Agent 处理的项目目录添加进来，然后**选中它**。

::: tip 选中工作区前输入框不可用
工作区决定了 Agent 能看到哪些文件、在哪个目录下执行命令。未选中工作区时，会话输入框处于禁用状态，这是预期行为。
:::

工作区的更多用法见[工作区与会话](./workspace)。

## 3. 运行第一个任务

新建一个会话，发送一条指令，例如：

```text
总结这个仓库的结构，并说明主要模块的职责。
```

Agent 可以读取与编辑工作区文件、执行命令、委派子任务并维护计划。如果某个操作按当前权限策略需要审批，界面会先向你询问，确认后才会执行。

## 4. 让它继续在后台跑

关闭窗口**不会**结束任务：宿主进程会继续驻留（可在托盘看到），任务完成后通过系统通知提醒你，点击通知即可回到对应会话。
