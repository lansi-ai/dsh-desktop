风险与技术债：

  • R5 closed（2026-08-26）：dsh-ui:// 自定义协议路径已实机验证（官方 dist 加载 + 资源 200 + bundle 送达）；BootSeams 方案 B 保留作回退未启用

  • R6 open !!js 表达式在 overlay patches（JS 对象直传 boot()）中不被 Cordis Loader 求值 —— 当前以 TS 直接求值绕过
  • R7 open session-persistence-jsonl / storage-json 的 root 路径使用硬编码 .runtime/user-data/...；待 dshHomePath 服务可用后切回
  • 暂存项：自绘 Desktop UI（U-01~08）按 P2 记账，ADR-006 启用前不投入
  • 步骤 6 --serve 传输层 no-op closed（2026-08-26）：DESKTOP_OVERLAY_PATCHES 仅以 {id:webserver,disabled:true} 打点，而 webserver/web-runtime/web-startup 行在 boot() 直传空 cordis.yml+patches 时从未被插入，故 --serve 原"解除 disabled"落空、无法绑定。已在 buildPatches serve 分支改为显式 INSERT webserver 行修复
